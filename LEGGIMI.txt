6. Premi Commit changes.

NOTA IMPORTANTE
GitHub Pages può mostrare la parte statica, ma NON esegue server.js. Per attivare le API occorre creare un servizio Web su Render collegato allo stesso repository. La variabile OPENAI_API_KEY va inserita solo nelle Environment Variables del servizio Render: non va mai scritta nei file o nel repository.
Le quotazioni possono essere ritardate e dipendono dalla disponibilità del provider. Le analisi sono informative, non consulenza finanziaria.
